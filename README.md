# Sanjay Balan – Data Analyst Portfolio

An interactive, responsive personal portfolio website showcasing data analytics, business intelligence dashboards, and machine learning systems built with SQL, Power BI, Tableau, and Python.

## 🚀 Live Preview & Running Locally

This portfolio is built with modern HTML5, Tailwind CSS, and vanilla JavaScript—requiring **zero build steps** and **zero dependencies**.

### Option 1: Open Directly
Double-click `index.html` in file explorer or open it in any web browser:
```bash
start index.html
```

### Option 2: Run Local HTTP Server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

---

## 🌐 1-Click Deployment

### GitHub Pages (Recommended):
1. Push this repository to your GitHub account (`sanjaybalan3294`).
2. Go to repository **Settings** ➔ **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your portfolio will be live at `https://sanjaybalan3294.github.io/`!

### Vercel / Netlify:
- Simply import this repository into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) — no build command or root directory overrides required!

## 🛠️ Features & Highlights

- **Confirmed Profile & Headline**: Customized to "Data Analyst" based in Coimbatore, Tamil Nadu (Open To Relocate).
- **Interactive Project Deep-Dives**: Detailed modals explaining the 4-Tier Analytics Ladder, data volumes, statistical findings, and direct GitHub links.
- **Dynamic Project Filtering**: Filter by All, AI & Machine Learning, Power BI & Tableau, or SQL & Relational Databases.
- **Animated Impact Counters**: Highlighting 54k+ sales records, 50k+ HR records, and 30k+ labor records analyzed.
- **Dark & Light Mode Switcher**: Preserves user theme preference using `localStorage`.
- **Contact & Direct Email Copy**: One-click clipboard copy for `sanjaybalan3294@gmail.com` with toast confirmation.
- **Full Responsive Design**: Optimized across mobile phones, tablets, laptops, and ultra-wide screens.
